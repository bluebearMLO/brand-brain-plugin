# Voice rules template → `02-voice-rules.md`

This is the "upload everything you've written, then turn it into voice rules" step. Read real copy (site, emails, newsletters, social, decks) before writing any rule. A rule nobody follows in the existing copy is a wish; label it that way.

```markdown
# <Brand> Brand Brain — 02 Voice rules

Source keys: ...

## 1. How we sound
3–6 traits. For each: one-line meaning + "Sounds like: ..." / "Not like: ..." pair.
Also list "We are not" traits if the brand defines them.

## 2. Words & phrases we use
### Locked lines (verbatim, never paraphrase): tagline, ritual/product lines, endorsement lines
### Calls to action (one per surface)
### Vocabulary we reach for

## 3. Words we never say
| Word / phrase | Why | Sourced or inferred |

## 4. Sentence & formatting rules
Length, rhythm, punctuation, capitalisation, headline style, numbers, spelling convention (British/American), emoji/hashtag rules.

## 5. Channel notes
Website · social · email/enquiry replies · B2B/partners · anything else the brand uses.

## 6. Truth rules (non-negotiable)
What may never be invented or claimed (prices, specs, clients, reviews, medical/financial claims, awards). How concept imagery is labelled. Placeholder data that must not be published.

## 7. Gold-standard lines
6–10 real lines quoted verbatim with file path. Also list "lines to retire": existing copy that breaks these rules.

## 8. Never print
Names and phrases that must never appear in public (suppliers, machine brands, NDA clients), with the reason.

## 9. Source conflicts
| Topic | Source A says | Source B says | Status (followed / wish / owner call) |
```
